# Quickstart: Validating the Indonesian UI

1. Build (`cd app && ./build.sh`): it compiles only if every `L.t` call has three languages (SC-001).
2. Install in place, open from Finder, pick **Bahasa Indonesia** in the sidebar picker.
3. Walk through My Mac, Steam (with its installed games), Compatible Games (a game page), My Games,
   My Apps (install form up to the file picker, a program page, the rename dialog): no English apart
   from product names and data-file notes (SC-003).
4. Quit and reopen: still Indonesian (FR-003).
5. Pick English, then Français: each is complete (US2).
