# UI Contract: Home and Theme

## Rail (top to bottom)

Home · My Mac · Steam · Compatible Games · My Games · My Apps, then the language menu at the foot.
Icons only; the name shows as a tooltip; the current section has a coral background.

## Home

1. Greeting with the user's first name and time of day, and a search field.
2. Hero banner: featured game art (scrim for legibility), title, state chip, primary action.
3. "Your games": installed Steam games and My Games programs, cover cards; click opens the page.
4. "Runs great on your Mac": hand-tuned gold games with a Steam id that are not installed.
5. Search results replace rows 2–4 while the search field has text.
6. Right column: Running now, Your Mac, Play time (total, top 3, "counted while MacPlay is open"),
   Recently added. When the window is too narrow for it, the same cards follow the rows.
