# Quickstart: Validating Chosen Covers

1. Build (`cd app && ./build.sh`), update `/Applications/MacPlay.app` in place, open from Finder.
2. Home → the Heartopia card shows "Choose a cover"; click it: the picker opens
   (contract: cover-picker.md).
3. "Search Google Images": the browser shows image results for Heartopia.
4. Open an image in full size, drag it into the picker: the preview shows it in the card's shape.
   Apply: the card shows it. Repeat with "Copy Image" + ⌘V, and with "Choose file…".
5. Drop a web page link or a text file: the picker says it is not an image; the preview is unchanged.
6. Right-click the hero → "Change banner…", apply a wide image; right-click → "Use default artwork".
7. Quit and reopen MacPlay: the chosen cover is still there.
8. Rename the program in My Games: same cover, same play time under the new name.
9. Switch to Bahasa Indonesia and Français: the picker's text is translated.
